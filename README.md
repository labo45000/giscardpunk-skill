# giscardpunk

Skill pour reproduire le style **GiscardPunk**, un rétrofuturisme français des années 1970-80 (archives imprimées, photos d'époque, typographies grotesques, palette chaude délavée), inspiré du compte Instagram [@giscardpunk](https://www.instagram.com/giscardpunk/).

## Installation

```bash
npx skills add OWNER/giscardpunk-skill --skill giscardpunk
```

Remplace `OWNER` par le compte GitHub du dépôt.

## Contenu

- `skills/giscardpunk/SKILL.md` : cinq familles visuelles, palette, typographie, cadrage, traitement de l'image, vocabulaire de prompts, checklist de fidélité.
- `skills/giscardpunk/references/palette-and-stats.md` : mesures de palette sur 801 visuels du compte.
- `skills/giscardpunk/references/images/` : 24 visuels de référence en 900 px.
- `skills/giscardpunk/references/contact-sheet-1.jpg` à `contact-sheet-3.jpg` : 144 visuels échantillonnés.

## Limites

- Les visuels appartiennent à leurs auteurs et proviennent du compte Instagram @giscardpunk. Ils sont inclus pour l'étude du style uniquement.
- Les couleurs d'accent vifs sont estimées à l'œil, pas mesurées.
- Le compte présente un univers imaginaire (uchronie). Ne pas présenter ses visuels comme des faits historiques.
