# Mesures du corpus GiscardPunk

Source : 801 visuels téléchargés du compte Instagram @giscardpunk (669 publications, carrousels inclus). Mesure faite sur des versions réduites à 96 px (BMP), en pixels cumulés. Les valeurs sont donc approximatives (± quelques points), mais la tendance est fiable.

## Tonalité globale
- Luminosité moyenne : 0,49 (échelle 0 à 1). Les tons moyens dominent : 65 images sur 801 sont sombres (< 0,3), 56 sont très claires (> 0,7).
- Saturation moyenne : 0,28. Le corpus est coloré mais pas flashy. Les couleurs sont souvent assourdies.
- Répartition des pixels : environ 40 % de tons chauds (orange, brun, beige, rouge), 19 % de tons froids (bleu, cyan), 35 % de neutres (gris, blanc, noir).

## Familles de teintes (parmi les pixels suffisamment saturés)
- Orange / brun / beige : 34 %
- Bleu : 19 %
- Jaune : 16 %

- Cyan / turquoise : 10 %

## Lecture pour la reproduction
- Partir d'un fond neutre (blanc papier ou gris béton) puis ajouter 1 à 2 accents vifs (rouge, jaune ou orange).
- Garder les tons chauds (brun, ocre, pêche) pour les photos. Les bleus restent en second rôle, sauf pour les ciels et les visuels 3D.
- Éviter les dégradés modernes et les couleurs fluo ou néon pures. Les couleurs doivent paraître imprimées et vieillies.
